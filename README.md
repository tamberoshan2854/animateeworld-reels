# animateeworld reels

Public video files that Buffer fetches (by raw.githubusercontent.com link) to publish reels:

- `reels/` - Hindi horror reels for Instagram @animateeworld and YouTube "Animatee world"
- `techwala/` - Hindi tech-news reels for Instagram @techwala.daily

Videos are only needed until they are published. A weekly clean-up keeps the last 7 days of videos and restarts the git history, so this repo stays small.
